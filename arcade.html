📋 Changelog: bugs fixed
  • Online lobbies failed on networks that block direct connections between players, and a dropped connection ended the game.
  • iPad: tapping near the edge of the screen closed the game by accident.
  • iPad: Fullscreen could get stuck on older iPads, with no way back out.
  • iPad: swiping in a game could scroll or bounce the arcade behind it, and long-pressing popped up the copy menu.
  • Slope 1 was loading Slope 2. Its link pointed at a site whose "Slope 1" player actually loaded Slope 2. It now uses slopeio.org's Slope 1.
  • PolyTrack couldn't be played inside the arcade, because every site hosting it blocked other sites from showing it. It now uses a version that can be shown in the arcade.
  • Games from other sites didn't get the keyboard until you clicked inside them, so arrow keys and WASD did nothing at first. The game now gets the keyboard as soon as it opens.
  • Pool cue showed up on the opposite side of the ball from where you clicked or dragged. It now sits on the side you click, and the shot goes the other way, like pulling a real cue back.
  • Pool computer never missed on any difficulty. It now misses by a realistic amount on Easy, Medium and Hard. Extreme (which used to be called Insane) is still perfect and breaks first.
  • Pool lobby got stuck for good if a friend's first try to join failed. The failed try took up the second spot, so every later join was turned away.
  • Pool lobby code stopped working if the host waited a while, even though the screen still said "Waiting for your friend". The lobby now reconnects by itself.
  • Pool lobby could hang forever on "Creating lobby…" or "Joining…". It now gives up after a few seconds with a message saying what went wrong.
  • Pool balls could pass right through each other on hard shots.
  • Pool balls could overlap and stick together, and collisions added made-up speed instead of passing it on like real balls.
  • Pool ran twice as fast on 120Hz screens.
  • Pool middle pockets almost never took a ball, because a ball had to arrive within about 10px of dead centre.
  • Pool balls could vanish in games against the computer, caused by timers left over from its practice shots.
  • Pool rack positions slowly drifted out of place over several games.
  • Game covers were all uploaded to the wrong folder and replaced each other, so no covers showed.
